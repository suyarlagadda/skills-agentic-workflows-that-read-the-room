## Recent updates worth watching

- **Stacked pull requests are generally available** (October 6, 2026): break large changes into smaller, focused pull requests that can be reviewed independently and merged together. Source: [GitHub Changelog](https://github.blog/changelog/2026-10-06-stacked-pull-requests-generally-available).
- **GitHub async merge API is generally available** (October 1, 2026): merge single or stacked pull requests, or add them to a merge queue, with a `PUT` request, then poll with `GET` for status. Source: [GitHub Changelog](https://github.blog/changelog/2026-10-01-github-async-merge-api-generally-available).
- **GitHub Copilot app for Beginners: teach Copilot about your codebase** (October 12, 2026): a beginner-friendly guide to giving Copilot project context. Source: [GitHub Blog](https://github.blog/ai-and-ml/github-copilot/github-copilot-app-for-beginners-how-to-teach-copilot-about-your-codebase/).
